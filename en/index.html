Install

Once installed it is just an icon in the menu bar; the first launch walks you through four permissions, and it updates itself.

Permissions & privacy

Screen Recording
Takes one screenshot the moment you press the hotkey.
Accessibility
Identifies the button, file or text under the cursor.
Finder Automation
Reads a file’s full path.
Browser Automation
Reads a web element’s URL, selector and styles.
  • Captures the screen only at the moment you press the hotkey, never continuously.
  • Uploads nothing, collects no analytics. The only network access is a daily check for updates.

Download the installer

  1. Download and open Ref-0.3.32.dmg.
  2. Drag Ref into Applications and open it from there. Don’t run it from inside the installer window — it can’t update from there.
  3. Allow the four permissions when asked.

FAQ

Why four permissions? Does it record my screen or upload anything?

Each permission does one job; see Permissions & privacy. Ref captures only at the moment you press the hotkey and uploads nothing.

How do updates work?

Ref checks for a new version once a day and installs it on its own; to check right away, use the menu bar icon → Check for Updates….

How do I start it at login? How do I quit or uninstall it?

Menu bar icon → “Settings…” → General → “Launch at login”. Quit: menu bar icon → “Quit Ref”. Uninstall: quit Ref, then drag it from Applications to the Trash; if you installed with Homebrew, run brew uninstall --cask ref.

Nothing happens when I press the hotkey

Check that all four permissions are allowed (menu bar icon → “Permissions…”); after turning on Screen Recording, Ref may need to be reopened. If they are all on, the hotkey probably clashes with another app: pick another under “Settings…” → General.

How do I get selectors and component names for web elements?

Turn on Allow JavaScript from Apple Events in the browser: in Chrome under View › Developer; in Safari under Settings › Developer (if that tab is missing, first check “Show features for web developers” under Advanced).

Some app gives nothing useful

Some apps expose no interface information to the system. Drag a region there instead and write a request.

The first click in Chrome or VS Code is a bit slow

Activating the accessibility interface takes a few seconds the first time. After that it’s fast.
