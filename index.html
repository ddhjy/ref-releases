问答

为什么要四项权限？会不会偷偷录屏或上传？

每项权限只做一件事，见权限与隐私。只在按下热键那一刻截图，不上传任何内容。

以后怎么更新？

每天自动检查一次新版本，有就自动下载安装；想立刻查，点菜单栏图标 → “检查更新…”。

怎么开机启动？怎么退出或卸载？

菜单栏图标 → “设置…” → “通用”里打开“登录时启动”。退出：菜单栏图标 → “退出 Ref”。卸载：退出后把“应用程序”里的 Ref 拖到废纸篓；Homebrew 装的执行 brew uninstall --cask ref。

按热键没反应？

先确认四项权限都已允许（菜单栏图标 → “权限…”）；“屏幕录制”打开后可能要重新打开 Ref。都开了还没反应，多半是热键冲突：到“设置… → 通用”换一个。

网页元素怎么读出选择器和组件名？

在浏览器里打开“允许 Apple 事件中的 JavaScript”：Chrome 在“显示 › 开发者”；Safari 在“设置 › 开发者”（没有这一页就先在“高级”里勾选“显示网页开发者功能”）。

某个 app 里读不出有用信息？

有些 app 不向系统暴露界面信息。改用拖拽框选，再写一句要求。

Chrome、VS Code 里第一次点进去有点慢？

首次激活辅助功能接口需要几秒，之后就快了。
