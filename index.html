Ref 是 macOS 菜单栏工具。按下热键冻住屏幕，点一点你想说的东西。Ref 自动读出它们是什么——哪个文件、哪个网址、哪个按钮、哪一行代码——编上号，连同你的要求合成一张自带标注说明的图，放进剪贴板。

截图只说了一半

想让 AI 改屏幕上的某个东西，你通常得这样描述：

“把左边访达里那个 components 文件夹……不是，是 src 下面那个……参考 Safari 里那个“新建发票”按钮的样式，在表格右下角那块空白加个导出按钮。”

这段话说不清，因为

  1. “那个文件夹”同名的文件夹不止一个。AI 要的是完整路径，截图里看不到。
  2. “那个按钮”截图里只有它的样子。它是哪个组件、写在哪个文件的第几行，AI 只能去猜、去搜。
  3. “那块空白”多大、从哪到哪，一句话说不准。

Ref 替你敲。你点到的每个元素，它都会读出那是什么，写进图下方的标注说明。你只需要补一句“想让它怎样”。

  1. 整体要求对整张图想说的一句话。什么都不标也可以只写这一句。
  2. 你的要求每个编号一行，写的是“想让它怎样”。
  3. Ref 读到的它是什么、在哪个 app、在屏幕的哪里。路径、网址、选择器完整写出，不省略。
  4. 签名标了网页元素时的页面网址，然后是屏幕尺寸、当时最前面的 app 和时间。

安装

两种装法，装上的是同一个包。Ref 没有主窗口，启动后只在菜单栏出现一个图标。第一次启动会打开“设置 → 权限”。屏幕录制、辅助功能、访达自动化、浏览器自动化四项都允许之后，才能开始第一次标注；每一项做什么，那一页里都写着。

常见问题

按热键没反应？

屏幕录制、辅助功能、访达自动化、浏览器自动化四项权限要全部允许。缺哪一项，按热键时 Ref 会列出来，并带你去“设置 → 权限”；“屏幕录制”打开后可能还要重新打开 Ref。四项都开了仍没反应，多半是热键和别的 app 冲突，去“设置 → 通用”换一个。

某个 app 里读不出有用信息？

有些 app 不向系统暴露界面信息，改用拖拽框选，再写一句要求。

网页元素怎么读出选择器和组件名？

在浏览器里打开“允许 Apple 事件中的 JavaScript”：Chrome 在菜单栏“显示 › 开发者”里；Safari 在“设置 › 开发者”里，没有这一页时先在“高级”里勾选“显示网页开发者功能”。没打开时，“设置 → 权限”的“浏览器自动化”一行会提示。

Chrome、VS Code 里第一次点进去有点慢？

首次激活辅助功能接口需要几秒，之后就快了。

下次要说“那个按钮”时，
按 ⇧⌘R。
